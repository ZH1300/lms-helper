# 国开学习网 LMS 学习助手

> 国开学习网（lms.ouchn.cn）课程学习辅助油猴脚本 —— 模拟人类观看节奏，自动按顺序完成图文与视频活动。

## ✨ 功能特性

- **真实播放优先** —— 视频静音 + 1.0~2.0 倍速区间随机波动，配合微暂停、回看、鼠标活动、阅读停留等拟人化行为，**不使用瞬时补进度接口**。
- **拟人化节奏** —— 随机倍速、随机微暂停、随机回看、模拟鼠标移动、图文渐进滚动阅读，每 6 个活动有概率进入休息。
- **自动按序完成** —— 读取课程结构，按模块 / 活动排序依次处理图文、视频、讨论区（仅浏览，不发帖）。
- **安全跳过** —— 测验、考试、作业一律跳过，不会产生任何作答或提交行为。
- **断点续刷** —— 页面关闭 / 刷新 / 崩溃后，重新打开会自动从上次位置继续，已完成活动自动跳过。
- **可折叠气泡面板** —— 面板支持拖拽、位置记忆、折叠为进度环形气泡，不遮挡学习内容。
- **策略可切换** —— 「真实播放」（推荐）与「接口补齐」（更快，但更易被学习行为分析识别）。
- **兜底上报** —— 长时间没有进度回报时，用**真实播放到的 `currentTime`** 区间补报一次，可随时关闭。

## 📦 安装

### 前置条件

1. 安装浏览器扩展：推荐 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox）或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 浏览器需允许在 `lms.ouchn.cn` 上运行用户脚本。

### 安装脚本

**方式一：从源码安装（推荐）**

1. 在 Tampermonkey 面板中点击「添加新脚本」。
2. 将本仓库的 `lms-helper.user.js` 内容完整粘贴，覆盖默认模板。
3. `Ctrl + S` 保存。

**方式二：直接拖拽**

将 `.user.js` 文件拖入浏览器窗口，Tampermonkey 会自动识别并弹出安装确认。

## 🚀 使用

1. 登录国开学习网，进入任意课程页面：`https://lms.ouchn.cn/course/{courseId}/...`
2. 右下角出现「学习助手」面板（可拖拽 / 可折叠）。
3. 面板会自动读取课程结构，读取完成后点击 **「开始学习」**。
4. 脚本将自动：
   - 进入全屏学习页
   - 按顺序打开每个活动
   - 视频静音播放并按配置调整倍速、微暂停、回看
   - 图文页面渐进滚动并模拟阅读停留
   - 讨论区仅浏览不发帖
   - 测验 / 考试 / 作业自动跳过
5. 完成后会在面板中显示 `全部完成 X / Y`。

> 💡 **建议**：首次使用时让浏览器标签页保持前台，或勾选面板中的「保持前台」，避免站点检测到切页自动暂停。

## ⚙️ 配置项

面板中的设置会即时保存到浏览器本地存储，下次打开自动恢复。

| 配置项 | 选项 | 默认 | 说明 |
| --- | --- | --- | --- |
| **策略** | 真实播放 / 接口补齐 | 真实播放 | 接口补齐会直接上报 0~时长区间，更快但**更易被识别** |
| **节奏** | 慢 / 自然 / 快 | 自然 | 控制活动间隔、阅读停留、休息概率 |
| **倍速** | 1x ~ 8x | 1.5x | 真实播放的实际倍速；拟人化模式上限为 2x |
| **拟人化** | 开 / 关 | 开 | 随机倍速、微暂停、回看、鼠标活动、阅读停留 |
| **保持前台** | 开 / 关 | 开 | 覆写 `document.hidden` / `visibilityState` / `hasFocus` |
| **兜底上报** | 开 / 关 | 开 | 长时间无进度时按真实播放位置补报 |
| **讨论区** | 开 / 关 | 开 | 进入讨论区浏览（不发帖） |

### 节奏参数参考

| 节奏 | 活动间隔 | 阅读倍率 | 休息概率 |
| --- | --- | --- | --- |
| 慢 | 7 ~ 15 秒 | 1.15x ~ 1.7x | 22% |
| 自然 | 4 ~ 10 秒 | 0.9x ~ 1.35x | 12% |
| 快 | 2 ~ 5 秒 | 0.55x ~ 0.85x | 5% |

## 🔒 隐私与安全

- 脚本**不收集、不上传**任何个人数据，所有配置与进度信息仅保存在本地（`GM_setValue` / `localStorage`）。
- 所有请求均通过 `fetch` 以 `credentials: 'include'` 携带当前登录态，与站内原生请求行为一致。
- 脚本**不会**填写测验、提交作业、发帖或进行任何可能违反学术诚信的操作。

## ⚠️ 注意事项

1. **自动化学习存在风险**：站点可能通过学习行为分析识别异常模式，请自行评估使用风险。**推荐使用「真实播放」+「拟人化」+「自然节奏」组合**。
2. **浏览器自动播放限制**：部分浏览器会拦截静音播放，若面板日志提示「浏览器拦截了自动播放」，请手动点击一次视频播放按钮。
3. **倍速限制**：部分播放器（如 Vue 多播放器）会限制 `playbackRate` 上限，脚本检测到达标失败时会提示，可尝试降低倍速。
4. **测验 / 作业请自行完成**：脚本仅辅助视频与图文类学习活动。
5. **建议保持前台**：切至后台可能导致站点暂停计时或停止心跳上报。

## 🧩 工作原理（简）

1. **课程结构读取**：调用 `GET /api/courses/{id}/modules` 获取模块，并发拉取各模块的 `all-activities`。
2. **进度读取**：调用 `GET /api/course/{id}/activity-reads-for-user` 获取完成度记录。
3. **活动切换**：修改 `location.hash`（AngularJS SPA），不整页刷新；超时则 `location.href` 硬跳转兜底。
4. **视频播放**：查找 `.online-video-activity` 内的 `<video>` / `<audio>`，静音 + 设置倍速 + `play()`；播放器拦截自动播放时自动点击大播放按钮。
5. **拟人化**：`human` 对象维护倍速波动、微暂停、回看、鼠标事件的定时器，`enforcePlay` 每 400ms 保活。
6. **兜底上报**：`lastProgressAt` 超过 90s 无变化且真实播放位置 `> 5s` 时，用 `currentTime` 区间 `POST /api/course/activities-read/{id}`。

## ❓ 常见问题

**Q：面板没有出现？**
A：确认已登录 `lms.ouchn.cn`，且当前 URL 匹配 `/course/{id}/...`。按 `F12` 查看 Console 是否有 `[LMS-AUTO]` 日志。

**Q：视频一直在「等待播放器」？**
A：可能是活动被前置条件锁住，或播放器需要手动点击一次。查看日志中的「没有找到视频播放器」。

**Q：接口补齐用了没用？**
A：接口补齐依赖站点接受 `{ start, end }` 区间上报。部分活动会返回 400 / 无法标记完成，脚本会自动回退到真实播放。

**Q：能跳过测验吗？**
A：能。脚本默认跳过 `exam` / `homework` 类型活动，并在日志中提示手动完成。

**Q：会发帖吗？**
A：不会。讨论区仅浏览，不发帖、不回复。部分课程可能要求回帖才算完成，此时面板会提示「未参与」。
